# Proyek Analisis Data: Bike Sharing Dataset

## Setup environment
```
pip install -r requirements.txt
```

## Menjalankan dashboard
```
cd dashboard
streamlit run dashboard.py
```

## Struktur folder
```
submission
├── dashboard
│   ├── main_data.csv
│   └── dashboard.py
├── data
│   └── hour.csv        (letakkan file dataset asli di sini)
├── Proyek_Analisis_Data.ipynb
├── README.md
├── requirements.txt
└── url.txt             (isi dengan link dashboard yang sudah di-deploy)
```
